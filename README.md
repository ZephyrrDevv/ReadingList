# Reading List Tracker

A simple reading list app built with vanilla JavaScript.
Add books to your list, track your total count, and remove the last added book.

## Features
- Add books to a dynamic list
- Remove the last added book
- Live book count badge
- Responsive layout (mobile friendly)

## Concepts Practiced
- `push()` — add a book to the array
- `pop()` — remove the last book
- `.length` — track total count
- DOM manipulation — `getElementById`, `innerHTML`, `textContent`
- Event listeners — `addEventListener`
- `renderList()` pattern — single source of truth for UI updates

## Tech Stack
- HTML
- CSS
- JavaScript (Vanilla)

## How to Use
1. Type a book title in the input field
2. Click **Add** to add it to the list
3. Click **Remove Last Book** to pop the last entry
